# Podcast criado com IAs Generativas

Este repositório contém o projeto completo de um podcast criado utilizando Inteligências Artificiais Generativas. Aqui você encontrará todos os prompts utilizados, áudio editado e assets do projeto.

## 📚 Sobre o Projeto

Um podcast profissional criado do zero utilizando:
- **ChatGPT**: Para escrever roteiros e scripts de alta qualidade
- **Eleven Labs**: Para gerar narração de áudio com vozes naturais
- **Midjourney**: Para criar imagem de capa atrativa
- **Ferramentas de Edição**: Para finalizar o áudio com qualidade profissional

## 🎯 Objetivo

Demonstrar como as IAs Generativas podem ser utilizadas para criar conteúdo de áudio profissional de forma rápida e eficiente, reduzindo custos e tempo de produção.

## 🎙️ Prompts Utilizados

### Prompt ChatGPT - Roteiro

```
Crie um roteiro para um podcast sobre Inteligência Artificial em Educação com os seguintes requisitos:
- Duração: 15 minutos
- Tom: Conversacional e educativo
- Público-alvo: Professores e educadores
- Estrutura: Introdução, 3 tópicos principais, conclusão
- Incluir 2-3 perguntas retóricas para engajar o ouvinte
```

### Prompt Eleven Labs - Geração de Áudio

```
Gere um áudio de narração para o roteiro do podcast:
- Voz: Feminina, profissional e com tom amigável
- Idioma: Português Brasileiro
- Velocidade: Normal (1.0x)
- Incluir pausas naturais entre parágrafos
```

### Prompt Midjourney - Imagem de Capa

```
/imagine prompt: Capa para podcast sobre Educação e Inteligência Artificial. 
Design moderno com cores vibrantes (azul e laranja), elementos de tecnologia 
e educação, composição equilibrada, aspecto 1:1, alta qualidade 4K, 
estilo: design gráfico contemporâneo
```

## 🔧 Ferramentas Necessárias

- Python 3.8+ (opcional, para processamento)
- FFmpeg (para edição de áudio)
- Acesso a APIs:
  - OpenAI (ChatGPT)
  - Eleven Labs
  - Midjourney (opcional)

## 📥 Como Usar Este Repositório

1. **Clone o repositório**
   ```bash
   git clone https://github.com/Hbini/podcast-ia-generativa.git
   cd podcast-ia-generativa
   ```

2. **Explore os prompts**
   - Acesse a pasta `/prompts` para ver todos os prompts utilizados
   - Adapte os prompts para seu próprio projeto

3. **Ouça o podcast final**
   - Acesse a pasta `/audio` para ouvir o podcast completo

4. **Use a imagem de capa**
   - Acesse a pasta `/imagens` para downloads da capa e thumbnail

## 💡 Insights e Aprendizados

- A combinação de IAs diferentes permite criar conteúdo profissional rapidamente
- Prompts bem estruturados são essenciais para resultados de qualidade
- Edição manual ainda é importante para polir o resultado final
- Feedback humano melhora significativamente a qualidade do conteúdo
